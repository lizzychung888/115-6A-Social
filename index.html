單元1

憲法三大義務 vs 基本權利

  • 三大義務：納稅（維持建設）、服兵役（保衛國家）、受國民教育（6~15歲，亦是權利也是義務）。
  • 平等權：法律之前人人平等（身障保障、育嬰津貼為合理差別待遇）。
  • 自由權：人身、居住遷徙、言論出版、秘密通訊、宗教信仰、集會結社（以不侵犯他人與社會公益為界限）。
  • 參政權：選舉、罷免、創制、複決、應考試服公職。
單元1

中央政府 vs 地方政府分工

  • 中央政府：總統（國家元首）、五院（行政、立法、司法、考試、監察），負責全國一致性法規政策。
  • 地方政府行政機關：直轄市/縣市政府、鄉鎮市區公所，執行道路維護、酒駕取締、環境消毒。
  • 地方政府立法機關：縣市議會、鄉鎮市民代表會，負責審議地方自治法規並監督首長。
  • 民意溝通管道：1999市民專線、公聽會、公共政策網路參與平臺（附議門檻5000人）。
單元2

社會變遷下的教育、家庭與性平

  • 教育轉變：早期重視升學主義、強制髮禁、著制服；現今倡導多元探索、解除髮禁、增設實驗教育。
  • 家庭型態：農業社會「子承父業」、「多子多孫」；工商業社會雙薪家庭增多，核心家庭、夫妻家庭、單人家庭比例攀升。
  • 性別觀念：打破「男主外、女主內」，推動性別平等教育日（4月20日），男性請領育嬰留職停薪津貼增加。
單元2

族群文化、多元信仰與建築融合

  • 信仰交流：原住民族敬畏祖靈自然；漢人帶來媽祖與王爺（東港迎王）；西方傳入天主教與基督新教；新住民與移工帶來伊斯蘭教（開齋節、不食豬肉）。
  • 建築融合：屏東萬金聖母聖殿（西班牙古堡風融合閩南奉旨石牌）；臺南鹽水天主聖神堂（中式宮殿與石獅子）；四四南村（眷村魚骨型建築轉型文化館）。

如何發布到 GitHub Pages？

只要簡單 4 個步驟，就能將此單一 HTML 檔案變為全班都能連線的線上複習網站：

  1. 在 GitHub 上新建一個公開儲存庫（Repository），例如：grade6-social-quiz。
  2. 將本檔案下載並命名為 index.html，上傳（Commit）到倉庫的根目錄。
  3. 進入倉庫的 Settings（設定） ➜ 點選左側選單的 Pages。
  4. 在 Build and deployment 下方，Branch 選擇 main，資料夾選 / (root) 並儲存。

等待約 1~2 分鐘，你的專屬網址就會出現在該頁面，可直接傳給學生或投影使用！
